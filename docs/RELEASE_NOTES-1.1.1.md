# 有梧 1.1.1

这一版修复蓝牙水表突然无法开水的问题，并补上结算数据的上传前校验。

## 修复：蓝牙水表无法开水

- 修复部分水表返回 28 字节状态帧时被误判为「设备未响应」的问题。旧版按 31 字节解析，遇到这种短帧会直接判定失败，开水和结算都无法继续。
- 28 字节与原有的 31 字节及以上布局分别按各自字段位置解析，不再把一种布局的偏移套用到另一种上。
- 状态帧中的「用水状态」与「设备故障」分开读取，不再把消费结束待采集误报成故障。
- 状态查询、关阀、采集消费数据三条命令补齐 SDK 要求的参数字节，与本表实际需要的一致。

## 修复：结算数据校验

- 上传结算前先校验设备回包：长度不足或首字节不是成功标记时直接提示重试，不再把设备错误应答当作消费数据上送。
- 结算数据本身不做裁剪或改写，仍按设备返回的原样上传。

## 说明

- 设备在上一笔用水已结束但未结算时（如上次中途退出），点开水会先自动补结算，完成后再点一次即可正常开水。
- 本次修复依据该水表的实测帧与公开 SDK 命令约定，未改变计费规则，也不会修改设备上的用水量。

安装要求：Android 8.0 及以上，正式安装包面向 arm64-v8a 设备。

升级说明：与公开版 1.0、1.1 使用同一签名，可直接覆盖升级并保留本机数据。

使用提示：蓝牙开水仍需靠近水表并允许蓝牙与附近设备权限。若提示状态待确认，请先到设备旁刷新确认，再继续操作。
