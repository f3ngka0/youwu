# 有梧 1.0

有梧的首个公开发布版本，将课程表与校园喝水、洗澡服务放在同一个应用里。

- 课程表：教务导入、周次切换、课程详情、离线缓存、自定义课程与课程管理。
- 课程表洞察：课程异动、课时与学分画像、学费参考统计、空闲时段分析。
- 喝水：独立账户登录、扫码或手动绑定、收藏设备与默认设备、一键启动。
- 洗澡：独立账户登录、余额查询、附近蓝牙设备扫描、扫码或手动绑定、蓝牙开关水与结算。
- 桌面组件：2×2 下一节课与 4×2 今日课程概览，支持倒计时、上课中、下课后、无课等状态。
- 个性化：学期与作息设置、周末显示、系统深浅主题、首次设置引导。
- 名称统一为“有梧”，项目采用 MIT 协议，保留第三方许可。
- 修正 Widget 横竖屏宽度选取；Android 12 及以上在异常偏高的桌面格子内限制卡片高度。

安装要求：Android 8.0 及以上；本次正式 APK 面向 arm64-v8a 设备。

公开安装包使用不含真实姓名或班级的独立发布签名。此前私人内测包采用不同签名，无法直接覆盖升级；请先处理好本机数据，再卸载内测包后安装公开版。

校园服务依赖已有服务账户、设备支持与校园网络环境。蓝牙洗澡需要靠近设备并允许相关权限。截图全部来自独立离线演示包，使用虚构课程、身份、设备与余额，不代表真实账户状态或现场设备测试结果。
