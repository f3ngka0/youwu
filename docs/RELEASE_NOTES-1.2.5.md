# 有梧 1.2.5

这一版修复了喝水登录被拒绝的问题，并把喝水与洗澡合并成一个「服务」页，另加外观设置。

## 修复：喝水登录提示升级客户端

服务端给登录接口加了签名校验：只在短信验证码正确后才校验，缺少签名会被回成「请升级最新版应用／请升级最新版客户端」，导致无法完成登录（已登录的旧会话不受影响，所以还能开水）。

- 登录请求改为 `acc/login?sign=<签名>`，签名为 `md5("authCode=<短信验证码>&un=<手机号>" + 盐)`。
- 登录请求体只保留 `authCode` 和 `un`；此前多发的 `cid`、`openCode` 也会被服务端拒绝。
- 短信验证码请求与登录统一使用 App 渠道（`ApplicationType 1,1`），版本标识回到与服务端要求严格配对的 `3.1.9`。
- 该签名算法与盐已用真实账号直连服务端验证：登录返回 `code:0` 并拿到设备会话令牌。

## 新增：服务页

- 底栏由 课程 / 喝水 / 洗澡 / 我的 改为 课程 / 服务 / 我的。
- 服务页顶部是「校园服务」标题，下面是带滑块动画的玻璃分段栏，喝水与洗澡在同一页切换，切换时内容淡入淡出。
- 两个服务原有的登录、设备卡片、扫码或手动绑定、更换设备、洗澡的账户与设备管理全部保留，选中项在切换 Tab 后保持。

## 新增：外观设置

- 我的 → 应用设置 → 外观，可选择跟随系统、浅色、深色。
- 选择立即生效并写入本机设置，重启后保留；系统状态栏图标会跟随所选明暗切换。

## 说明

- 本次没有改动课程表同步、洗澡开水的蓝牙流程与桌面组件行为。
- 设备启动仍不自动重试：超时或结果不明时会提示先确认设备状态，避免重复扣费。

安装要求：Android 8.0 及以上，正式安装包面向 arm64-v8a 设备。

升级说明：与公开版 1.0 至 1.2.0 使用同一签名，可直接覆盖升级并保留本机数据。
