# 有梧 1.1

这一版重点改进喝水与洗澡的使用体验，新增桌面快捷控制，让设备和账户更容易辨认。

## 新增桌面快捷控制

- 新增喝水、洗澡两种 2×2 桌面组件，可直接启动饮水或开启、关闭热水。
- 添加组件后，点击它手动选择设备；洗澡组件还需要选择开水账户。
- 每个组件独立保存绑定，首页切换设备或账户不会改变组件设置。点击右上角可重新绑定。
- 修复洗澡组件长设备名被按钮遮挡的问题。长名称适配空间，保留首尾并省略中间部分；完整名称可在绑定页查看。

## 洗澡账户与设备管理

- 支持验证并绑定第二个手机号，开水前可选择使用哪个账户。
- “设备管理”更名为“账户与设备管理”，每个账户下分别显示余额。
- 支持为账户添加备注，首页账户选择和洗澡组件会显示备注，方便区分。
- 绑定多个水表时，可直接在洗澡首页更换设备。

## 页面与控制体验

- 喝水与洗澡采用一致的页面结构，以蓝色和暖陶色区分服务。
- 喝水首页直接提供“扫码绑定”和“手动输入设备编号”。
- 精简标题与常态提示，减少重复信息。
- 蓝牙开水回执较慢时先等待确认，避免刚点击就出现红色错误提示。
- 用水中或状态待确认时保留原账户归属；重复点击不会排队重发开水请求。

安装要求：Android 8.0 及以上，正式安装包面向 arm64-v8a 设备。

升级说明：正式版与公开版 1.0 使用同一签名，可覆盖升级。debug 测试包签名不同，不能直接覆盖安装正式版。更换安装前，请保存需要保留的本机数据。

使用提示：蓝牙洗澡仍需靠近设备并允许相关权限。若状态待确认，请先查看设备并刷新确认，再继续操作。
