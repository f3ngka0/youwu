# 2×2 组件长名称适配

问题：真实桌面的2×2组件比180dp预览更紧凑，名称换为两行后，文字被底部按钮遮挡，账户行也缺少稳定空间。

修复：改用纵向约束布局。标题与主动作保持独立高度，名称区分配剩余高度；设备名仅占一行，字号在12–14sp范围内适应可用空间，过长时中间省略，保留开头与房间编号等末尾信息。账户备注独立显示一行。含账户的洗澡组件不再叠加第三行历史状态，状态仍在控制结果页与主按钮无障碍描述中呈现。名称无障碍描述保留完整文字，点击名称或设置可进入绑定页查看全名。

沿用蓝色与暖陶色，不改变绑定、账户归属或开关水流程。目标验证只看144dp正方形长名称组件的一张截图，不检查其他界面。
