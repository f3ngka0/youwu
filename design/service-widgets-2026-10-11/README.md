# 账户余额、备注与生活服务桌面组件

设计方向：保留现有灰白背景、圆角卡片与轮廓图标，用饮水蓝色和洗澡暖陶色区分服务。两个2×2组件保持同结构；服务名、设备名、洗澡账户备注和主动作构成信息层级。组件只是固定目标的快捷控制入口，不根据首页默认项自动改绑。

洗澡首页移除余额卡，“设备管理”入口及二级页标题改为“账户与设备管理”。每个已登录账户单独显示余额、来源和读取失败提示，可添加最多24字的本机备注。首页选择框、选择列表和洗澡组件使用该备注，空备注回退脱敏手机号。余额分别向平台读取，某个账户失败不会覆盖另一个账户金额，也不会自动切换控制账户。

新建桌面组件保持未绑定；用户点击后手动选择设备，洗澡组件还必须选择账户并保存。每个组件独立保存设备编号及账户手机号，不存凭据。失效的登录或设备会要求重新绑定，不自动选择其他账户或设备。右上角设置入口可重新绑定。可从系统组件列表添加，也可通过现有小组件预览页中的“喝水与洗澡 · 桌面组件”入口添加。

喝水组件显示“启动饮水”；洗澡根据持久化会话显示“开启热水”“关闭热水”或“确认状态”。用户点击后进入简短状态页，前台处理蓝牙权限和蓝牙开启提示，然后执行现有控制流程；成功后返回桌面，失败留在结果页。不通过后台自动开阀，不重发超时请求。首页与组件共享非排队操作锁；饮水启动尝试写入本机10秒冷却，避免不同组件重复启动。

沿用Material按钮与单选项的按压反馈、对话框过渡、进度指示；RemoteViews组件本身不添加循环动效。删除首页余额卡后，把金额与账户归在同一区域；桌面按钮不使用“蓝牙”技术前缀。设备名称可在绑定页查看完整内容。

仅采集并检查 `widgets-latest.png` 一张目标截图，两个组件在同页，使用虚构设备与备注。它由实际RemoteViews管线渲染，每个180dp×180dp，Android15模拟器1080×2400。Oil UI独立审查同图，不打分。根据意见统一设备名首行位置，洗澡按钮改为“开启热水/关闭热水”。未采集其他页面、未检查全界面。
