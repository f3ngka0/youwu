# 有梧 1.1.2

这一版修复 1.1.1 之后喝水功能突然无法使用的问题。

## 修复：喝水无法启动

服务端更新后按请求头里的客户端版本号校验，旧版本号会直接拒绝启动，并提示「请升级最新版app」。本版把喝水相关请求的客户端标识更新到与官方客户端一致，设备启动恢复可用。

- `VersionCode` 与 `User-Agent` 更新为官方客户端 3.1.9 的值，覆盖登录、短信验证码、验证码图片、设备列表、设备状态、收藏绑定和启动。
- 设备启动请求补齐 `args`、`cnt` 参数，与官方客户端一致。
- 服务端业务错误与网络错误分开处理，便于判断失败原因。

## 修复：登录失效被误判为「没有设备」

凭据失效时设备首页仍返回成功码，但数据里没有账户信息。旧版会把这种情况当作「账户下没有设备」，界面上看不出需要重新登录。

- 现在识别为登录已过期，直接提示重新登录。
- 只有真正没有收藏设备时才显示空设备状态。

## 改进：启动前状态检查

- 启动前先查询设备状态：离线或已被禁用时直接给出对应提示，不再发出注定失败的启动请求。
- 支付方式：钱包扣费相关失败时才改用支付宝免密重试；超时不重试，避免重复启动和重复扣费。
- 扫码绑定时先向服务端换取真实设备编号再收藏；手动输入设备编号不额外请求。

## 说明

- 本次只改喝水服务的请求标识与错误处理，未改变课程表、洗澡、桌面组件的行为。
- 设备启动仍不会自动重试：超时或结果不明时会提示先确认设备状态，避免重复扣费。

安装要求：Android 8.0 及以上，正式安装包面向 arm64-v8a 设备。

升级说明：与公开版 1.0、1.1、1.1.1 使用同一签名，可直接覆盖升级并保留本机数据。
