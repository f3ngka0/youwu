# 有梧 1.2.0

这一版新增了通知中心，并重做了手动添加课程的流程，新增课程笔记功能。

## 新增：学习通通知中心

现在可以在设置登录学习通。登录后，可以在首页卡片打开通知中心。

- **待办**：发布在学习通的作业、考试等日程会自动列入待办，你可以随时查看进度。
- **课表异动**：发布在学习通的调课通知会自动列入课表异动并填入课程表，手动核对后可以在课程表上看到调停课的最新信息。
- **通知原文**：发布在学习通的所有通知会纳入这个框，可以按未读、作业/测验、签到、课程公告筛选，也可以用关键字搜索。

已读、归档、作业标记完成都只存在本机，不回写学习通服务端，不影响官方 App 的未读状态。

## 新增：课程笔记

课程详情页里可以给一门课记作业、课堂笔记和考点，支持文字与图片，可以加提醒。

- 笔记列表点开是只读的查看页，图片能正常看；要改再进编辑。
- 提醒可以选「今晚 20:00」「明天 8:00」这类快捷项，也可以自定义日期与时间。
- 提醒到点会发一条系统通知，点通知直接回到那门课的详情页。

## 重做：手动添加课程

原来的表单是一堆加减按钮和开关，现在可以直接在课表上排课。

- 点课表空白格就地出现半透明的草稿块，之后拖动可以按涂抹范围调整节次。
- 拖色块上沿或下沿可以拉长缩短，拖色块主体可以换天换节。
- 只有网格里点不出来的东西才留在底部表单：课程名、教室、教师、周次预设。

## 其他

- 课程图标按课程名匹配矢量图标，覆盖数学、物理、化学、计算机、机械、经管、文史、艺术、体育等常见类别；匹配不到时退回首字母。
- 新增通知与闹钟权限：`POST_NOTIFICATIONS`、`SCHEDULE_EXACT_ALARM`。
- 学习通登录协议与通知中心接口改造自 [Xuexitong-mcp](https://github.com/DanMo661/Xuexitong-mcp)（MIT），许可信息已加入 `THIRD_PARTY_NOTICES.md`。

## 说明

- 学习通账户与教务、喝水、洗澡账户相互独立。登录使用学习通手机号与密码；平时只用短信登录的，需要先在官方 App 设置密码。
- 只读取通知中心（作业、考试、教师与学校通知，课程公告会混在其中）；私信没有可用接口，不包含在内。
- 网络请求只读取通知列表，不执行签到或提交作业。
- 学习通密码、Cookie 与教务密码一样使用 Android Keystore 加密保存在本机。

安装要求：Android 8.0 及以上，正式安装包面向 arm64-v8a 设备。

升级说明：与公开版 1.0、1.1、1.1.1、1.1.2 使用同一签名，可直接覆盖升级并保留本机数据。
